# Codex Anywhere Android 0.6.7

面向自托管 Codex Anywhere 中继的非官方 Android 客户端。原生 Java 界面负责设备选择、会话列表、文字记录、草稿、请求状态和权限选择；本地打包的 JavaScript 模块负责设备认证、WebSocket 和端到端加密。不可见的 WebView 仅加载固定的本地协议资源，不加载远程聊天页面。

## 会话同步

- 打开会话或从后台返回时立即同步。App 在前台通常每秒检查当前会话；收到会话推送时会提前更新。读取失败时，常规重试间隔为 15 秒。
- 手机发送后先显示消息和当前发送状态；确认写入会话记录后合并为一条。未确认的消息不自动重发。
- 「发送指令」会优先使用桌面原生输入。连接器确认原生通道不存在时，自动通过桌面的兼容通道投递同一条文字。投递结果待确认时请先同步记录。
- 输入框上方显示当前会话的模型与思考强度。点击可选择模型及其支持的强度。使用桌面兼容通道时，设置在后续兼容发送时生效。
- 已选电脑重新上线时重建连接并恢复会话读取；读取失败时保留当前消息。
- App 在前台时会尝试恢复因临时断网或认证到期而断开的中继连接。中继断开期间清除旧设备状态，区分手机未连中继与电脑离线。

## 任务通知

- 点击顶部「通知」→「开启通知」。Android 13 及以上需要在系统提示中选择允许；也可以在此入口打开系统设置。
- 当前选择的电脑和会话有任务完成、失败、等待审批或等待输入时，可收到系统通知。点击通知回到对应会话。通知不会显示消息、命令或项目路径，锁屏上隐藏内容。
- 当前电脑从在线变为离线时会提醒；点击通知可查看电脑列表。手机与中继的连接断开时，不会误报电脑离线。
- 电脑需要运行新版连接器。通知通过现有的加密连接发送；App 退到后台且连接仍在线时也可以收到。App 被系统停止、断网或强制退出后不会收到离线推送。

## 电脑上的 Codex 账号

顶部“账号”强制刷新所选电脑的 Codex 原生账号和工作区列表，避免缓存只返回当前工作区；同时读取当前工作区的订阅类型。可选择已有登录下的工作区，或使用“登录其他账号”发起 OpenAI 官方设备码授权。验证码只保存在内存中；手机不接收账号令牌，也不保存登录密码。已有登录能否继续列出取决于电脑 Codex 的原生账号会话管理能力。

同一登录下的个人订阅（例如 Pro）与 Business 团队工作区可在列表中直接选择，无需重新登录。每个工作区显示原生名称和个人／团队类型；当前所选工作区显示真实读取的订阅类型，未选中的工作区不推断套餐。

账号弹窗中的「Codex 额度」显示电脑所选账号的剩余百分比和重置时间。打开弹窗或选择「刷新账号和额度」时读取一次。重置时间按手机本地时区显示。

当前 Windows 桌面版可能缓存登录状态。账号更新后会显示待重启提示；点击“重启 Codex”并确认，才提交电脑桌面应用的重启请求。此操作会中断桌面任务。自动重启仅支持当前用户安装的 OpenAI.Codex Windows 应用；其他安装形式需手动重启。手机会每两秒查询重启状态，只有旧桌面进程退出且新进程启动得到确认时才显示重启完成；失败和超时会显示原因。状态写入本机独立操作记录，断线后重新打开账号弹窗可恢复读取。连接器只保存不含账号身份的待重启标记、操作编号和执行结果，登录凭据由 Codex 管理。Windows PowerShell 使用隐藏的普通子进程启动，避免分离进程模式下未执行脚本就退出。

需要同时更新本机连接器，且电脑 Codex 支持 accountSession/list、accountSession/switch 和 chatgptDeviceCode 登录接口。当前安装版本已只读验证原生账号列表和 Windows 重启预检；其他账号授权和实际桌面重启由用户操作，未用真实账号执行测试。

## 弹窗与配对

- 连接、电脑选择、会话权限与完全访问确认统一为深蓝渐变、浅紫强调的底部卡片；平板居中展示。
- 连接页提供带标签的地址与配对输入框、扫码入口、输入焦点、加载状态和行内错误。校验不通过时保留输入。
- 设备卡片区分在线、离线、当前设备和待选择状态，确认后才切换电脑。
- 权限卡片说明各模式，取消不保存；完全访问保留独立确认和连接器能力校验。
- 键盘弹出时内容可滚动，底部操作按钮保持可见。
- 配对成功清除已使用链接；取消连接使旧握手失效，旧连接回调不能影响新的连接尝试。

## 使用与限制

点击顶部“连接”，扫码或粘贴十分钟单次配对链接。已配对时可留空重新连接。再从顶部选择在线电脑，通过左侧会话栏打开会话。

支持 sessions.list、session.read、turn.start、turn.stop 及当前会话权限读取与修改。停止桌面所有者任务仍可能需要更完整的轮次参数。未确认的消息不自动重发。

当前不包含新建会话、原生附件传输、完整 Markdown、原生审批卡片或常驻后台服务。审批或输入提醒可定位到会话，处理请在电脑或支持该操作的 Web 界面完成。设备私钥保存在 App 私有设置中，Android 备份关闭。系统浏览器与 App 配对身份独立。

## 构建与验证

Windows 上运行 powershell -ExecutionPolicy Bypass -File build.ps1。依赖 JDK 21、Android SDK platform/build-tools 35、libs/zxing-core-3.5.3.jar。修改协议模块后须先通过 esbuild 打包 engine/protocol.ts 至 assets/protocol.js。

产物为 out/CodexAnywhere-0.6.7.apk。本地开发签名位于 out/development.jks，须保留以便覆盖更新，不要发布该密钥。

历史消息加载和前台自动同步曾在小米 13 / Android 16 验证。消息发送状态、历史解析和连接恢复有独立测试。
